# 📰 Fake News Detection System

This project is a machine learning-based application that classifies news articles as **Fake** or **Real** using Natural Language Processing (NLP).

## ⚙️ Tech Stack

* Python
* Pandas
* Scikit-learn

## 🧠 How it Works

* News text is converted into numerical form using **TF-IDF**
* A **Logistic Regression** model is trained on real-world data
* The model predicts whether input news is fake or real

## ▶️ How to Run

1. Install dependencies:
   pip install pandas scikit-learn

2. Run the program:
   python fake_news.py

3. Enter news text to get prediction

## 📊 Dataset

Download the dataset from Kaggle:
Fake and Real News Dataset

Place `Fake.csv` and `True.csv` in the project folder before running.

## 🎯 Features

* Real-time prediction
* Uses real dataset
